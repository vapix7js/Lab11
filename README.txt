ЛАБОРАТОРНАЯ РАБОТА №1 — ВАРИАНТ 13
PostgreSQL / pgAdmin 4

СОДЕРЖИМОЕ
- lab1_full.sql — полный скрипт: создание таблиц, заполнение и контрольные SELECT.
- create_tables.sql — отдельный скрипт создания таблиц и связи.
- insert_data.sql — отдельный скрипт заполнения (10 строк в каждой таблице).
- cascade_test.sql — безопасная проверка каскадного обновления и удаления.
- kafedry.csv — 10 записей для таблицы kafedry.
- prepodavateli.csv — 10 записей для таблицы prepodavateli.
- ERD.png — ER-диаграмма двух таблиц и связи 1:N.

КАК ЗАПУСТИТЬ В pgAdmin 4
1. Создайте базу данных variant_13.
2. Выберите эту базу и откройте Tools → Query Tool.
3. Откройте lab1_full.sql через File → Open и нажмите Execute (F5).
   ВНИМАНИЕ: lab1_full.sql пересоздаёт таблицы kafedry и prepodavateli.
   Если в них уже есть нужные данные, предварительно сохраните их.
4. Проверьте результат: в обеих таблицах должно быть по 10 записей.
5. При необходимости отдельно выполните cascade_test.sql.

CSV
- Кодировка UTF-8 с BOM.
- Разделитель полей — точка с запятой (;).
- CSV не содержит IDENTITY-столбцы: номера создаются автоматически при выполнении SQL.
- Если импортировать CSV вручную, импортируйте поля в указанном порядке, включив Header.

СТРУКТУРА И СВЯЗЬ
- kafedry.nomer_kafedry — первичный ключ, автоинкремент.
- prepodavateli.kod_prepodavatelya — первичный ключ, автоинкремент.
- prepodavateli.nomer_kafedry — внешний ключ на kafedry.nomer_kafedry.
- Связь: одна кафедра может иметь несколько преподавателей (1:N).
- ON UPDATE CASCADE и ON DELETE CASCADE включены.
- kod_fakulteta — обычное поле INTEGER, так как таблица Факультеты не входит в 13 вариант.
